About

How Curio defines relevance and ranks results.

Task

Rank Chinese museum images from a natural-language query (English or Chinese lexicon) using attribute-compositional ranking.

Relevance

Strict relevance needs all stated period / material / object type constraints. Graded nDCG credits partial matches. Each result shows match or conflict evidence.

Method

Multi-prompt CLIP (full query plus period, material, and type prompts) fused with soft attribute gates. BM25 remains an explicit metadata baseline.

Data

Met and Cleveland CC0 Chinese collections — a fixed gallery sized for attribute-balanced experiments.
